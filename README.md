# OMEGA CodyAI Chatbot Logs

Private WordPress plugin repo.

- `plugin/` is the installable WordPress plugin root.
- `release/build-zip.command` builds `release/dist/omega-cody-<version>.zip` from `plugin/`.
- `release/deploy.env.example` documents optional SFTP upload settings. Copy it to `release/deploy.env` locally; do not commit credentials.
